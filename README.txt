How it works:
1. Customer opens the website.
2. Clicks ORDER NOW.
3. Fills name, phone, quantity and address.
4. The order message is prepared for SR Shopping BD WhatsApp.

Free publishing:
- Upload these files to a static hosting service such as GitHub Pages.
- After publishing, use the website URL as the destination for your Facebook website/action button.

Important:
- Change the price in index.html if 770 is not the final price.
- Change the WhatsApp number in index.html if your order number changes.
